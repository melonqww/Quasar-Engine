# Публичный Changelog

Здесь отмечаются крупные изменения и вехи, заметные на уровне проекта. Подробная хронология разработки публикуется в [Devlog](DEVLOG.md); небольшие технические шаги остаются в истории коммитов.

## Unreleased

### Добавлено

- Первая база интерфейса по согласованному концепту: нейтральные серые панели, янтарные акценты, компактные вкладки и действия, вертикальные инструменты, Console и начальное переключение Basic/Advanced. Document viewport теперь рендерится в отдельную область с учётом DPI.
- Первый публичный снимок Quasar Engine на ранней альфа-стадии: техническая проба редактора, тестовая сцена и отдельный Player.
- Подготовлено описание данных для эксперимента с анимацией: ключи трансформации, звуковые события и ссылки на импортированные клипы.
- Добавлено общее воспроизведение анимации двери и импортированных GLB-клипов, вкладки Scene Timeline и Clip Preview, а также сохранение и повторная загрузка snapshot в Editor.
- Начат этап 1: введён отдельный версионированный `ProjectDocument`/`SceneDocument` со стабильными UUID и атомарным сохранением; Stage 0 snapshot остаётся отдельным форматом.
- Подключён минимальный Player preview для активной `SceneDocument` с локальными transforms и иерархией объектов.
- Добавлен read-only MCP-адаптер для чтения открытого в Editor проекта, списка сцен и содержимого сцены.
- Начат этап 2: Editor получил общую сессию `ProjectDocument`, проверяемые команды сцены, revision/dirty tracking и Undo/Redo с объединением transform-жеста в одну запись.
- Для `ProjectDocument` добавлен отдельный документный интерфейс: иерархия и выбор объектов, создание/удаление, инспектор имени и transform, gizmo Move/Rotate/Scale, Undo/Redo и Save. Объекты в viewport пока представлены placeholder-кубами.
- MCP получил `preview_scene_command`, `apply_scene_command`, `undo`, `redo` и `save_project` поверх общей сессии Editor; операции записи требуют актуальную `expected_revision`.
- Добавлены стабильные AssetId и sidecar metadata, библиотека Assets и локальный импорт GLB/PNG/JPEG/WAV до 512 MiB с проверкой и staging.
- Модели GLB можно назначать объектам через Inspector; назначение поддерживает Undo/Redo, а Editor и Player загружают модель по AssetId.
- Импорт/reimport и загрузка по прямому HTTP(S) URL выполняются как отслеживаемые jobs с прогрессом и отменой; URL и авторство/лицензия сохраняются в metadata.
- MCP получил список ассетов, локальный/URL-импорт, reimport, чтение/отмену job и назначение модели объекту через общий слой Editor.

### Подтверждено

- В рамках Stage 0 вручную проверены отображение тестовой сцены, базовое управление персонажем, столкновение со стеной, взаимодействие с дверью и звуком, а также отдельный Player.
- Автоматический smoke-запуск Player подтвердил загрузку `Idle`/`Walking`, переключение клипа, звуковое событие двери и завершение анимации.
- Автор вручную подтвердил работу вкладок, редактирования анимации, сохранения/повторного открытия и Player; этап 0 закрыт.
- Сквозной smoke подтвердил, что MCP читает через открытую Editor-сессию тот же Stage 1 fixture: проект, активную сцену, два объекта и revision 0.
- Живой MCP-прогон через запущенный Editor подтвердил preview без мутации, stale revision conflict, создание/переименование/transform/reparent, удаление поддерева с Undo/Redo, Save и загрузку результата в новой Editor-сессии. Ошибочная ссылка на родителя отклонена без частичной мутации.
- Document mode открылся на отдельной копии fixture; viewport и панели дерева/инспектора видны в screenshot. Изменения документа проверены через MCP; клики по UI-контролам требуют отдельной ручной приёмки.
- Проверка asset slice прошла 73 workspace-теста и Clippy с `-D warnings`; Editor и Player отрисовали временный документ с импортированной GLB-моделью. Отдельный MCP-процесс проверил локальный импорт, каталог, назначение модели, Undo/Redo и Save. Положительная загрузка с публичного URL и ручные клики по UI ещё не подтверждены.

### Ограничения

- `RobotExpressive` остаётся временной тестовой моделью; постоянную модель персонажа выберем позднее.
- Текущая оболочка остаётся техническим прототипом; интерфейс и продуктовые решения продолжают развиваться.
- В document viewport объекты без назначенной модели пока показываются кубами; typed component пока поддерживает GLB-модель, не материалы, текстуры и аудио.
- URL-загрузка требует системный `curl.exe` в PATH, поддерживает только прямой URL без редиректов и принимает только публичные адреса.
- MCP работает с одной открытой Editor-сессией; скрипты, материалы, текстуры, аудио и полный игровой цикл ещё не подключены.
- Document viewport пока показывает объекты простыми кубами; picking, полноценное отображение компонентов и ручная проверка действий через UI ещё впереди.
- Asset workflow прошёл только сборочную проверку; ручные проверки UI/Player и сквозных MCP jobs ещё предстоят.
