# Проверка данных

Проверяются версия формата, непустые имена, уникальность project/scene/object UUID, active scene, внутрисценовые parent-ссылки и циклы, конечные значения transform, нормированный quaternion, ненулевой scale, type ID/version компонентов. Возвращаются сообщения с ID объекта; UI здесь нет. Валидация asset payload начнётся вместе с каталогом ассетов на этапе 3.
