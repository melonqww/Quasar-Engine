# Точка входа Player

Парсит `--snapshot`, читает и валидирует versioned JSON snapshot, канонизирует каталог ассетов и проверяет наличие всех файлов до запуска окна. Stage 0 создаёт одну тестовую комнату и использует общие Lua/physics runtime-модули. `--validate-only` даёт headless-проверку пакета; `--lua-probe-only` оставлен как узкий тест из этапа 0.2.
