# Редактор

Авторский рабочий процесс: панели, изменения документов, preview, импорт, Advisor, Play и export. Не реализует вторую игровую физику или отдельный runtime.

Первая визуальная база следует концепту редактора: нейтральные серые панели, отдельные янтарные акценты, компактные вкладки/действия, вертикальные инструменты и Console. Одна тема используется в Stage 0 и document mode; недоступные функции отключены с пояснениями. Basic/Advanced пока переключает технические подробности. Document viewport рендерится в отдельную texture с учётом размеров панелей и DPI.

Для технической сессии постоянного проекта можно передать `--project-document <path>`: Editor откроет отдельный document mode с иерархией объектов, выбором, созданием/удалением, инспектором, transform controls и gizmo, Undo/Redo и Save. Сцена строится из того же `ProjectDocument`; объекты без назначенной модели пока показаны placeholder-кубами, viewport picking ещё не подключён. В этом режиме Editor публикует локальную сессию для `quasar-mcp`.

В document mode вкладка `Assets` показывает библиотеку из sidecar metadata. Импорт GLB, PNG/JPEG и WAV до 512 MiB доступен по локальному пути или через direct HTTP(S) URL. Jobs показывают статус, байтовый прогресс и отмену; reimport может взять новый local source path или сохранённый URL. Выберите объект сцены и его модель справа в Inspector; назначение сохраняется как стабильный AssetId, отменяется через Undo и отображается в Editor/Player. URL-импорт требует `curl.exe` в PATH и не следует редиректам. Текстуры и аудио уже учитываются в каталоге, но пока не назначаются scene components.
